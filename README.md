# 💰 Kendali Pengeluaran

Aplikasi web sederhana untuk mencatat dan merekap pengeluaran/pemasukan pribadi per bulan.

## ✨ Fitur
- 📊 Dashboard ringkasan keuangan bulan ini
- 💳 Kelola transaksi (tambah, edit, hapus)
- 📅 Rekap bulanan dengan grafik harian & tren 6 bulan
- 🏷️ Kelola kategori pengeluaran/pemasukan
- 💵 Setting budget bulanan
- 📤 Export data ke JSON & CSV
- 📥 Import data dari backup
- 📱 Responsive (mobile-friendly)
- 💾 Data tersimpan otomatis di browser (localStorage)

## 🚀 Deploy ke GitHub Pages

1. Buat repository baru di GitHub (misal: `kendali-pengeluaran`)
2. Upload semua file ke repository
3. Buka **Settings** → **Pages**
4. Pilih branch `main` (atau `master`) dan folder `/ (root)`
5. Klik **Save**
6. Aplikasi akan tersedia di `https://username.github.io/kendali-pengeluaran/`

## 🛠️ Teknologi
- HTML5, CSS3, JavaScript (Vanilla)
- LocalStorage untuk penyimpanan data
- Canvas API untuk grafik (tanpa library eksternal)

## 📝 Catatan
- Data tersimpan di browser masing-masing user
- Gunakan fitur Export untuk backup data
- Tidak ada backend/server yang dibutuhkan
